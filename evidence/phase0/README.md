# Phase 0 Evidence

This tree holds reviewable Phase 0 evidence only. Committed event-level inputs must be deterministic, product-stamped synthetic fixtures. Live observations are reduced to aggregate counts and require provenance, artifact hashes, and a conclusion; raw or unreviewed live traces are ignored.

Each future spike directory must contain a SHA-256 manifest and an `SP-*-CONCLUSION.md`. Task 1 creates only this policy and the approved synthetic fixture location; it records no experiment result.
