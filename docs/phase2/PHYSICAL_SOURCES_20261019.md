# 物理按键依据：来源连接与失效处理

日期：2026-10-19。第四批范围为来源连接、失效处理及信息不足时的逻辑回退。真实设备、Keychain 恢复、卸载和发布验证继续后置。

## 问题与实现

此前分析入口只传递 VIA 文件产生的几何/固件参考，当前 Karabiner Profile 未进入物理来源，完整观测也没有产品组合端口。文件内容不足以证明当前键盘已经应用配置，更不能证明完整固件→软件→macOS 变换链。

本批新增 `PhysicalSourceInput` 和来源报告，把当前 VIA 配置/定义、选中或连接的 Karabiner Profile、连接端当前版本及推荐作用域传入分析。软件参考只转换能严格表达的规则；设备限制、未知修饰键侧别、Fn 和其他应用范围不会变成无条件映射。Vial 不能借用 VIA 文件几何。所有文件/Profile 映射仍是参考，设备身份未知、反向覆盖不完整，不获得已生效资格。

`ProductHostBoundaries` 接入完整观测和变更通知端口，分析候选及手动候选共用会话模型。界面显示位置、设备、固件、软件和 macOS 五项来源状态，并由用户显式重新检查。默认生产观测返回空；真实设备身份、当前固件及 macOS 完整映射适配器仍待实现与实测。模拟端口可提供完整链，沿用既有 `PhysicalAnalysis` 校验，不改变排名或宣称人体工学收益。

## 撤销与回退

- 文件/定义变化、Profile 或后端切换、软件版本变化、映射变化、隐私关闭及周期切换撤销已有观测，取消读取和监听；重新打开或恢复旧字节不会复活旧结果。
- 使用时重新读取来源状态和连接端版本，不等待文件通知；每个作用域独立保留观测，应用证据不能复用为全局证据。
- 重新检查先撤销旧结果。读取失败、来源失效、错误作用域、迟到响应及最终复核期间发生的撤销均不能保留旧成功结果。
- 既有完整链、单一设备、唯一反向映射及覆盖检查保留。任一侧信息不足，两侧一起使用逻辑按键数，不混合物理与逻辑口径。手动候选随依据变化重新检查。

## 离线验证

使用临时 VIA 配置/定义、Karabiner 配置、加密临时库和模拟观测端口；没有操作真实键盘或真实用户配置。

- 包测试覆盖文件参考保持未合格、Vial 不借用 VIA 几何、Profile 选择、应用范围和完整链要求。
- 原生模型覆盖完整模拟链的 2→1 按键比较、定义替换、恢复原字节、Profile/后端/隐私变化、通知撤销、版本先于文件通知变化、异步迟到、读取失败及最终复核撤销。
- 中英文原生界面通过辅助功能打开来源明细、点击重新检查，观察物理结果出现及来源撤销后回退。初次 DisclosureGroup 的辅助功能动作未展开；改为显式展开按钮后同一操作通过。
- 产品组合测试确认宿主观测端口收到当前 Profile 和版本；默认空观测保持参考/缺失状态。

本地全量包测试 816 项通过；原生离线回归 121 项通过（101 项映射/文件流程、18 项导入流程、2 项生产组合/退出），arm64 Debug build-for-testing 通过。最终命名调整后的 4 项来源包测试另行通过。PR 与合并后 main 的 CI 结果以实际运行记录为准。构建、截图和模拟完整链均不建立真实后端或设备资格。
