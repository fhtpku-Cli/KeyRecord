## 本批补齐的行为

候选生成现在接受后端能力值，在截取最多三个触发前过滤原组合输出端和触发端的键码/Fn 能力。产品按当前后端意向重新生成逻辑预览，资格门槛、原始统计、70% 默认作用域规则不改变；不支持应用作用域时明确说明，不把用户意向偷偷改成全局。参考键码格式不等于当前后端版本兼容。

`CandidateConflictDetector` 消费当前周期的快捷键/应用桶、既有系统规则表及类型化后端规则证据。观测和系统风险属于警告；规则重叠、映射环和保护入口属于阻断。规则重叠覆盖触发、作用域、设备和配置方案；环搜索在整条路径上累计交集，避免把不同应用或设备的规则拼成假环。处理复杂度超出有界搜索时明确未知。检查结果包含覆盖证据和缺失信息，未发现冲突不等于无冲突。

缺观测、未知应用归属、缺后端规则、未解析规则、方案不匹配、部署仅为副本或实际后端版本未知，都不能升级为检查通过。应用菜单没有读取，始终列为未覆盖的部分证据；不申请辅助功能权限。检查输入包含实际规则、观测身份、方案、设备范围和普通版本号等模型值，输入改变即撤回旧结果；没有新增 hash、冻结 contract、baseline 或 gate。

设置新增可选的 Karabiner JSON 配置副本读取和方案选择。解析标准基础规则、明确侧别修饰键及严格锚定的单一应用条件；保留规则顺序。简单改键/Fn 表可提示终止键重叠，但其修饰键传播和动态动作仍未解析，不声称完整。正则范围、设备条件、时序、变量、Shell、未知码或其他不支持结构计入未解析项，既不执行也不持久化其内容。只保留规范化的会话内参考；文件变更、清除、隐私关闭、旧读取及旧选择器回调均不能继续提供证据。

读取复用 VIA 已有的只读、普通文件、拒绝符号链接、非阻塞和有界 JSON 保护，保持已有隐私 generation、句柄监测及安全作用域释放。产品没有自动读取日常 Karabiner 配置、查询设备或调用后端命令。VIA 静态副本和几何继续提供部分参考；完整部署/变换链缺失时整个比较保持逻辑口径。

自动候选及手动草稿均展示能力/冲突报告，证据改变时手动风险确认失效。外部映射创建、写入、导出、读回、回滚和紧急停用仍属 Phase 3/4。当前产品的实际后端保持未连接，配置副本不会把它变成已连接。

解析依据为 [Karabiner 配置结构](https://karabiner-elements.pqrs.org/docs/json/root-data-structure/)与[修饰键规则](https://karabiner-elements.pqrs.org/docs/json/complex-modifications-manipulator-definition/from/modifiers/)；支持子集有意保守，不据文档存在推断本机运行版本。

## 原有需求的开发覆盖

| 要求 | 工程覆盖和证据范围 |
|---|---|
| FR-R1 确定性及解释 | 逻辑排名与物理量分开；能力过滤和冲突结果确定性；规则版本组合覆盖本次新增行为 |
| FR-R2/R3 资格及衰减 | 原有计数/跨日/14 活跃日规则保留；能力变化不改变资格及原始统计 |
| FR-R4 数量上限 | 能力过滤在截取前三项之前；Top 5/全部候选分开，仍只展示正向简化 |
| FR-R5 声明边界 | 完整唯一物理链才输出次数/跨度；两端同口径，缺失整对回退；没有时间/健康收益承诺 |
| FR-R6 作用域 | 70%/未知分母/同分规则不变；检查实际选择的应用或全局意向，后端不支持时明确拒绝 |
| FR-R7 候选约束 | 默认空的确认功能键池、自动无裸可打印键、手动风险二次确认，确认不绕过能力/冲突条件 |
| FR-E1 几何与证据链 | VIA 简单几何/标准参考解析、规范链消费、唯一逆向、完整回退及失效；真实部署与系统/软件链继续缺失 |
| FR-E2 布局询问 | 沿用一次询问和现有偏好事务，后端意向与参考导入不会重开询问 |
| FR-U 相关界面 | 原生方案选择/清除、双语证据报告及 AX 标签；实际文件选择器授权、键盘/VoiceOver 体验集中留后 |
