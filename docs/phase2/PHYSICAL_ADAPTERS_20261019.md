# 第五批：物理按键来源适配器

日期：2026-10-19。基于第四批合并提交 `92111ab9859be6d89d23f9e0a1e4023f0d53148c`；该提交 main CI 已成功。本批只开发与离线验证，真实设备、Keychain 恢复、卸载和发布验证后置。

## 实际接入

1. macOS：App 层通过公开的 `IOHIDEventSystemClientCreateSimpleClient`、键盘服务枚举和 `IOHIDServiceClientCopyProperty` 读取每个服务的 `UserKeyMapping`，不调用写属性 API、打开键盘或注册按键事件。分析模块只接收模拟/真实端口返回的事实，保留原模块导入限制。
2. Karabiner：在显式重新检查时读取本机主配置（默认 `~/.config/karabiner/karabiner.json`，支持进程内绝对 `XDG_CONFIG_HOME`），要求恰好一个明确 `selected: true` 且名称不重复的 Profile，与当前选择的副本内容、Profile 和已知版本比较。复用有界只读文件端口及文件身份监测。该事实表示主配置选择，不证明守护进程已应用。
3. Vial：复用既有兼容检查、显式设备选择、只读协议和加密读回确认；`PhysicalFirmwareReadbackAdapter` 消费实际返回的键码，接受既有 Vial 方言中的标准名称和十六进制表示，保留层/矩阵位置。未知及复杂动作不猜测，不建立完整反向覆盖。恢复副本或下一操作更新、隐私清理会撤销会话中的读回参考。

来源报告新增“已读取部分依据，完整映射未确认”。设备服务枚举可能包含虚拟服务，既不推断单一物理键盘，也不把服务 ID 当历史统计的设备归属；`UserKeyMapping` 缺失、空表及多服务状态分别保留。以上数据不补恒等链，不改变逻辑排名或既有物理解析校验。

## 失效处理

系统采集逐项读取服务属性，并复核读取前后的注册服务身份；同数量服务替换也拒绝接纳。使用观测前再次比较系统快照、文件身份和版本，变化就永久撤销该观测，恢复旧值也不复活。文件变化通知、应用切换及唤醒会撤销会话；没有轮询或定时任务。系统属性没有被本批声明为持续实时监听，使用前复核是必要路径。

后台采集通过既有保护代次访问文件，隐私撤销取消读取任务；迟到结果仍受第四批的会话与输入复核约束。结束会话取消文件监听，模型释放时取消任务和通知订阅。某项不可读只显示缺失/参考，不能沿用旧成功状态或获得完整链资格。

## 验证与自审

- 模拟系统端口执行真正的逐服务采集器，验证属性读取、空/缺失状态、重复身份、非法字段、采集中设备替换；未运行真实系统读取。
- 临时 Karabiner 主配置验证唯一明确选中、错误 Profile、内容变化、文件原子替换和版本变化。读取途中隐私关闭后，配置读取不再启动，结果不显示。
- 模拟 HID 执行既有 Vial 协议，实际读回进入来源报告；未知设备继续受原兼容检查限制。即使读回成功，设备和活动层/时序仍未知，继续逻辑回退。
- 中英文原生界面显示部分依据及逻辑口径，生产组合测试以模拟系统端口和临时配置执行正式适配器。
- 初次回归发现 Vial 十六进制键码被漏掉，以及分析模块意外引入 IOKit；已修复转换并把原生系统访问移回 App 层，保留原模块边界测试。

最终本地全量包测试 820 项通过，原生离线回归 125 项通过（105 项映射/文件流程、18 项导入、2 项生产组合/退出），arm64 Debug build-for-testing 通过。自审未发现剩余阻断项；PR、push 及合并后 main CI 以本批实际运行记录为准。

未新增持久 hash、冻结 contract、baseline 或 gate。兼容检查、加密恢复副本及删除前复核保留。没有恢复浏览器实例绑定或定时任务。

## 剩余边界

下一步是设备/几何对应、固件活动层与时序、软件实际生效与执行顺序以及 macOS 完整事件变换。一次主配置读取、一次键码读回或一张空系统映射表都不覆盖这些事实；正式物理收益仍需完整链及真实验证。本批不宣称完整 Phase 3/4 或公开发布合格，完成后停止。

来源范围参考：[Apple TN2450](https://developer.apple.com/library/archive/technotes/tn2450/) 说明 `UserKeyMapping` 查询机制；[Karabiner 配置位置](https://karabiner-elements.pqrs.org/docs/manual/misc/configuration-file-path/)及[配置结构](https://karabiner-elements.pqrs.org/docs/json/root-data-structure/)说明主配置及 Profile 选择。实际原生接口签名同时核对当前 Xcode SDK 的公开 hidsystem 头文件。
