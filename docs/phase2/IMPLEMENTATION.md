## 已接入产品的流程

受保护的当前周期聚合进入概览、全部候选和设置。Top 5 保留符合资格、未忽略且有正向逻辑简化的项目；无可用方案的组合仍可查看原因。忽略/恢复、布局偏好和特殊键池通过原加密事务保存，排队操作在隐私/周期变化后拒绝旧结果。打开统计不开始采集，Pause 不变成 Resume。

候选生成已连接后端能力与有范围的冲突检查，手动触发有明确风险确认。推荐可进入[后端草稿](../phase4/RECOMMENDATION_HANDOFF_20261019.md)：Karabiner 保留组合和应用范围；VIA/Vial 当前编辑器只接全局基础改键，显式选兼容副本及匹配位置。不把组合快捷键降级成一个基础键。

## 逻辑排名与物理比较

`phase2-logical-v1` 保持确定性逻辑排名：加权频次、可减少逻辑键数、来源因子和布局因子。资格仍要求原始计数至少 20 次且跨至少两个本地自然日；衰减半衰期为 14 个活跃日，作用域默认阈值 70%，Top 5、每项最多三个候选不变。

物理结果独立输出按下次数与同坐标系键位跨度，不把距离换算成“等价按键次数”，不改变逻辑排序。只有几何、设备与完整固件/软件/系统链及逆向覆盖明确且唯一可比时才消费物理结果；任一侧不足，原组合与候选整对使用逻辑口径。跨分体坐标未知时不比较跨度，不推断疲劳、疼痛或历史每次动作。

## 实际来源与失效

| 来源 | 已实现 | 不能据此证明 |
|---|---|---|
| VIA 配置及原始/编译定义 | 有界解析、型号/拓扑核对、支持子集的简单几何、文件身份监测 | 文件已部署、活动层、真实键盘效果 |
| Karabiner 配置/Profile | 选中副本与主配置/明确当前 Profile、版本和内容比较 | 所有规则实际生效、完整执行顺序与其他软件链 |
| macOS 键盘服务及 `UserKeyMapping` | 实际适配器读取系统属性，模拟端口覆盖采集前后变化 | 服务就是物理设备；空属性意味着全链恒等 |
| USB 型号/布局对应 | 唯一厂商号、产品号和连接方式匹配；歧义拒绝 | 历史输入归属、确切布局版本或同型号键盘的唯一身份 |
| Vial 自身定义与键码 | 同次读回保留定义，两次定义一致性检查，逐层矩阵坐标对应 | 持续当前性、活动层、设备原子快照或完整链；不借用 VIA 几何 |

来源会话、通知、显式重新检查已进入生产组合。文件、Profile、版本、设备身份、后端或隐私变化撤销旧结果，迟到结果不能复活；Vial 旧快照撤销后必须重新设备读回，恢复原属性或普通刷新不足以重新授权。

详见[来源会话](PHYSICAL_SOURCES_20261019.md)、[适配器](PHYSICAL_ADAPTERS_20261019.md)、[设备布局](DEVICE_LAYOUT_20261019.md)和[Vial 定义](VIAL_LAYOUT_20261019.md)。这些适配器以模拟系统/设备端口、临时文件和原生离线流程验证；生产来源尚不具备完整真实物理资格。

## 数据与验证边界

分析不保存逐事件顺序或设备归属，无法从旧聚合恢复历史层状态和按住时长。若未来增加采集维度，须先确定产品与隐私范围；当前来源估算不隐含这项授权。

活跃日顺序由归约器显式提供，已有独立加密周期对象保存该顺序；旧资料库缺失此对象时保留旧的时间排序回退，不猜测历史。原始固件文件由后端加密副本流程保存，物理来源展示和观测快照保持其会话范围，不能把早期只读导入器“不保存原件”的说明外推到整个产品。

[验证记录](VALIDATION.md)按批次保留结果；当前交付与 CI 见[项目状态](../PROJECT_STATUS.md)。未恢复浏览器实例绑定或定时任务，不安排新的真实验证。
