# 实机配合操作指南

当前合并版已完成一次单页安全输入回归，见 [结果记录](PR10_SINGLEPAGE_REGRESSION.md)。下一轮不自动开始。执行者在整轮开始前确认你方便并取得该轮批准，之后按本页连续操作，不要求你在密码框聚焦期间回聊天。

调试版放在单独目录里运行，不会替换你正在使用的 KeyRecord。执行者不会改系统权限、不会锁屏、不会唤醒电脑、不会输入按键，也不会打开你的真实统计数据。

三次测试分开做，不要连在一起。每次开始前，执行者会重复下面这句话：现在要做哪一次、大约多久、你需要做什么、怎样算结束。

## 每次开始前

请确认：

- 你有大约下面写明的空闲时间，并且可以留在这台电脑前。
- 电脑接上电源，不要让它自动睡眠。测试本身不会阻止睡眠；如果中途睡眠，这一次作废。
- 暂停状态、登录时启动、以及“不统计哪些应用”保持你平时的设置。测试结束时也保持原样。
- 只用执行者当场指定的一个普通文本窗口和两三个普通快捷键，例如保存。不要输入文章、密码、账号或私人内容。

执行者会先给你一个单独的调试版，并告诉你它已经打开。在那之前，不要自己去打开日常使用的 KeyRecord。

## 1. 暂停时的资源测量

目的：看程序在“已暂停”时占用多少处理器和内存。

时间：大约 11 分钟。更短的测量只用于检查工具，不能当作这次结果。

步骤：

1. 等执行者说调试版已经打开。
2. 点菜单栏里的 KeyRecord，选择“暂停”。如果已经是暂停，就不要点“继续”。
3. 告诉执行者：“已经暂停。”
4. 之后约 11 分钟不要打字，不要锁屏，不要切换用户，不要合上电脑。
5. 执行者说测量结束前，不要退出。
6. 结束后，用菜单里的“退出”关掉这个调试版。不要强制结束进程。

这一次不需要你输入任何快捷键。

## 2. 锁屏后是否停止，以及解锁后是否自己恢复

目的：看锁屏期间统计是否停止，解锁后会不会在你没有点“继续”的情况下自己开始采集。

时间：大约 3 分钟。锁屏保持大约 1 分钟。

这次开始时程序应处于暂停。不要和上一次资源测量连在一起；那次已经退出。

步骤：

1. 等执行者打开一个新的调试版，并确认菜单显示暂停。
2. 在执行者指定的普通文本窗口里，只按事先约定的快捷键一次。记下屏幕上相关数字。不要输入正文。
3. 你自己锁屏。执行者不会替你锁屏。
4. 保持锁屏大约 1 分钟。不要输入密码以外的内容；解锁用你平时的方式即可。不要把密码告诉执行者。
5. 解锁后先不要点 KeyRecord 菜单里的“继续”。
6. 看统计是否仍是锁屏前的数字，并告诉执行者：数字变了还是没变，菜单现在是暂停还是在采集。
7. 用菜单“退出”。

如果执行者另一次明确说“这次要看恢复采集”，解锁后才点“继续”，然后再按一次约定快捷键。没有这句说明，就不要点“继续”。

## 单页安全输入回归（采集中）

目标：已在正常采集时，安全输入开启会停采并隐藏统计，关闭后自动恢复。
这与“暂停时不能自行恢复”是两个场景，分开运行。全程约 2–3 分钟，不混入锁屏。

执行者先准备 [本地单页夹具](../Scripts/fixtures/secure-input-test.html)，在浏览器中打开，
确认仍处于准备页、没有密码框，再启动本轮独立 Debug 和新的诊断文件。
确认正常采集且见证为 disabled 后，一次性交接以下全部步骤，并持续读记录直到退出。
不得结束回复后声称仍在观察，不要求用户回来发“已完成”。

1. 确认菜单显示正在采集，回到测试页点击“已在采集，开始本页测试”。之后不要切窗口。
2. 页面普通文本区按 ⌘A 三次，每次完全松开、间隔一秒；点击“已按三次”。页面等待 5 秒自动保存。
3. 点击“进入密码框步骤”才会创建并聚焦密码框。先按页面等待 5 秒，再输入 `aaa` 一次，保持聚焦直到 30 秒倒计时结束。不要使用真实密码。
4. 用鼠标点击“结束密码框步骤”。密码框被移除，普通文本区获得焦点，等待 5 秒。
5. 在普通文本区再按 ⌘A 两次，点击对应完成按钮，等待页面的保存倒计时。
6. 页面提示操作完成后，用鼠标从 KeyRecord 菜单退出。无需回聊天，执行者直接核对退出摘要和进程消失。

计时只引导操作，不证明系统安全输入已开启或恢复成功。必须有独立 enabled/disabled
读数和完整关闭边界，才评估对应区间；没有见证、见证到期、页面中止或记录缺失均不能报完整通过。
本页不读取输入值、不联网、不保存按键；按钮是用户的操作确认，不替代实际计数证据。
测试期间切窗口会中止；密码框保持阶段失焦也会中止并移除输入框。
中止后正常菜单退出，不强杀，也不在同一轮无限重试。300 秒见证窗口从启动开始计算。

## 怎样算正常结束

执行者确认这次的记录已经写好，你用菜单“退出”。单页安全输入轮次不需回复；其他需要协调的场景按当轮说明。

## 这些情况要停下来

出现任何一种，就停止这一次，用菜单退出；退不出时再告诉执行者。这一次不能下结论，需要另约：

- 电脑睡眠、你切换了用户，或屏幕意外锁屏。
- 调试版自己消失，或你被迫强制结束它。
- 测试过程中输入了本轮约定内容以外的内容（单页轮次约定包含测试字母 aaa）。
- 执行者没有在开始前问你是否方便。

## 结束后你的电脑

暂停、登录项和排除名单保持测试前的样子。调试版退出后，不会留在你的日常启动项里。执行者不会替你改这些设置。
