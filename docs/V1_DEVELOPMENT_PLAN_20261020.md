## 保留的边界

批次 A 的来源依据：Apple IOKit 的 `VendorIDSource` 属性及 [Bluetooth Device Information Service 1.2 §3.9](https://www.bluetooth.com/wp-content/uploads/Files/Specification/HTML/DIS_v1.2/out/en/index-en.html) 的 PnP ID 定义。蓝牙 source 2 才使用 USB-IF 厂商编号；source 1、未知值或缺失值不匹配 VIA 型号。USB 保留未提供/零值来源的兼容行为。同型号多个服务仍判歧义，不采集持久设备标识。模拟端口已复现采集中映射变化仍成功返回的问题，修复后 11 项来源/身份测试通过；`Scripts/verify-local.sh --firmware-app-tests` 已通过全部包测试、离线捕获回归、Release 构建、通用未签名 App 构建与指定原生回归。文档相对链接及索引无缺失；历史第三方站点路由引用不改写。

批次 B：原先旋转或布局选项使整份几何不可用，现按显式输入计算受支持矩形的中心和可选位置。VIA 官方 Save/Load 不导出布局选择，因此 UI 只提供临时参考选择，不修改配置文件；重导入和隐私撤销清空选择。Vial 仅使用同次读回的 `layout_options`，按 labels 的位宽解码，缺失/保留值不猜零；定义没有选项时不以无关选项数值否定几何。读回允许跳过矩阵空洞，但每个选中的实际键位必须存在。原始 KLE 旋转选项组、VIA/Vial 定位规则不一致的错位选项组、二级形状、旋钮及未知几何继续回退；不因此宣称支持所有 KLE 表示或完整物理链。

官方对照入口为 `Scripts/via-definition-oracle.cjs`；V2/V3 生成结果由 `VIAReferenceParserTests.testOfficialCompilerAgreesWithSelectedOptionsAndRotation` 比较坐标，沿用现有 CI。Vial 位编码来源为既有锁定版本的 `editor/layout_editor.py`，选项定位差异见 `widgets/keyboard_widget.py`；只按协议语义自行实现，不复制 GPL 实现到产品代码。

批次 B 本地验收：全量包测试、离线捕获回归和 Release 构建通过；首轮原生测试发现矩阵空洞检查回归，修复后 132 项原生测试全部通过，最终 22 项解析/读回专项测试通过。官方生成的 4 份 V2/V3 旋转/选项用例与 Swift 坐标一致。原有布局变化测试改为改变键间距（归一化原点后，整份布局平移不改变键间几何），保留撤销旧观察和新几何不同的断言。

- 真实 HID、Keychain 恢复、真实卸载、平台性能、签名/公证/发布验证均后置；仅使用模拟端口、临时文件和离线测试。
- 删除前复核、恢复副本、未知版本阻断及现有兼容检查保留。

## 完成条件

批次 C 的普通导出是可读 JSON 配置记录，并非 VIA/Vial/Karabiner 官方导入文件，也不是完整恢复备份。它从资料库 actor 的一次同步快照只读取偏好与映射记录，排除统计、原始固件、宏、恢复前镜像、机器路径和临时行为测试规则；导出路径已有文件时拒绝覆盖，隐私撤销后拒绝迟到结果。完整恢复继续使用密码备份。Dock 偏好默认关闭并兼容旧记录，保存失败不会假装成功；映射应用或用户声明固件导入后仅提示新周期，真正重置仍进入删除前复核。

后续 C2 依据 PRD X2/X3：只在用户发起时读取所选正在运行应用的菜单快捷键，权限拒绝或不支持时保持提示级。菜单证据只能补充冲突提示，不能证明应用实际效果，也不能采集窗口标题、文本或键序。

C2 已接入设置入口、当前应用识别、限定菜单属性读取、临时内存快照、候选冲突及实际 Karabiner 准备上下文。PID 与启动时间不匹配、取消、选择变化或既有隐私会话失效均放弃结果；无权限时仍可继续映射。读取限制为 2 秒、2048 节点、16 层，仅处理系统提供的虚拟键码和修饰键，字符/字形表示不会被猜测为键码。菜单始终是部分证据。842 项包测试、离线捕获回归、SwiftPM Release、双架构未签名 App 和 139 项原生测试通过；原生按钮在中英文中实际触发模拟读取并显示拒绝后的降级提示。真实辅助功能权限与各应用菜单覆盖需后续验证。

来源：Apple [菜单修饰键属性](https://developer.apple.com/documentation/applicationservices/kaxmenuitemcmdmodifiersattribute)，以及随 Xcode SDK 提供的 `AXAttributeConstants.h` 和 `AXUIElement.h` 的键码、位定义和消息超时说明。仅读取菜单树的角色、子节点和快捷键属性，不读取标题或窗口信息。

批次 C 本地验收：841 项包测试、离线捕获回归、SwiftPM Release 和双架构未签名 App 构建通过；自审修复无 AppKit 实例的模拟宿主崩溃后，135 项指定原生测试全部通过。普通导出覆盖取消、目标已有文件、选文件时隐私撤销、异步结果返回前隐私撤销；命名测试保留原始固件字节和状态，周期提示测试确认没有自动重置。沿用既有隐私审计登记新增字段及导出 DTO，未放宽未知类型检查。

交付闭环条件是每项可执行增量有实际执行证据、PR 合并和对应 main CI。最终报告分别列出完成的开发、尚需产品决定的事项、实际无法提供的来源能力和必须真实验证的事项；只有没有开发或产品阻塞时，才可以说“只剩验证”。

D/E 本地验收：846 项全量包测试、捕获工具 19 项 CLI 场景和 6 项离线检查、SwiftPM Release、双架构未签名 App、159 项原生离线测试通过。随后新增二进制审计反例与相关 14 项定向测试通过；4 项发布脚本模拟共 24 个断言通过。原生更新流程中英文实际点击检查、查看和确认；静态发布源码、包结构和联网检查通过。核心框架多余导入引起的首轮测试失败已修复，原检查保留。最新完整包测试数量将包含新增反例，不能拿前一轮数字充当最终 CI 结果。
