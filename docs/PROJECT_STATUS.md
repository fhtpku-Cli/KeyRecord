# 当前开发状态

更新日期：2026-10-20（Asia/Shanghai）。正式名称 **KeyRecord**，自有代码 **Apache-2.0**。本轮已完成来源一致性、布局表达、用户流程、菜单冲突参考、更新检查和发布工具的离线实现；PR、对应提交 CI 与 main CI 记录见 [v1 执行计划](V1_DEVELOPMENT_PLAN_20261020.md)。[逐项需求核对](V1_REQUIREMENT_AUDIT_20261020.md)区分已实现工程、真实验证以及仍缺平台来源的目标。

**不能宣称完整 v1 已完成或已可公开发行。** 限定 Apple Silicon MVP 有历史实测，新增流程有离线证据；macOS 14+ / Intel 的生产采集来源、真实后端资格和正式发布仍未闭环。

## 最近完成的开发

| 范围 | 实际变化 | 限制 |
|---|---|---|
| 来源一致性 | 系统映射采集前后复核、蓝牙厂商号命名空间区分、设备身份歧义处理 | 不记录逐事件设备归属，不把型号匹配当唯一设备身份 |
| 布局与选项 | 矩形旋转、明确布局选项、VIA 临时参考选择、Vial 同次读回选项 | 原点平移不影响相对几何；复杂形状/错位选项组/未知输入回退 |
| 用户流程 | 普通配置导出、草稿与批次命名、应用后新周期提示、Dock 偏好、菜单栏推荐徽标 | 导出不含统计/原件/宏/恢复镜像；新周期仍经删除前复核 |
| 可选菜单参考 | 用户主动读取所选应用的菜单快捷键，接入候选冲突及 Karabiner 准备上下文 | 权限拒绝不阻塞映射；应用重启、取消、隐私变化使证据失效；不读标题或窗口内容 |
| 更新与许可 | 每周固定 GitHub 查询，显式确认打开版本页；Apache-2.0 和第三方声明随包可读 | 手动下载安装，不自动替换、不传统计；真实分发未验证 |
| 发布工具 | Universal archive、签名身份检查、公证、staple、Gatekeeper、最终 ZIP 的可执行工具与模拟失败测试 | 本轮没有实际签名、公证、发布或安装 |

本轮完整本地回归执行了 846 项包测试、19 项捕获工具 CLI 场景与 6 项离线检查、双架构未签名 App 构建、159 项原生离线测试，均通过；随后新增二进制审计反例和相关定向测试通过。测试数只属于本轮版本；完整原生测试包、真实设备和发布验证不能据此算通过。远端最终提交结果以执行计划链接为准。

## 下一步的具体边界

1. **先解决平台来源阻塞。** 当前生产锁屏读取仅启用原生 arm64 macOS 27+。较旧 macOS/Intel 的可靠来源尚需确认，再决定适配器接入；最低编译目标和 Universal 构建不能代替这项能力。不直接放宽平台检查。
2. **安排有范围的真实验证。** Karabiner 重载与行为、VIA GUI 导入、Vial 只读 HID、Keychain 恢复、完整卸载、可访问性、性能和发布链分别记录具体版本/设备/动作。
3. **保持既有分析范围。** 历史聚合没有逐事件设备/时序，不可能补回历史活动层或物理动作。当前证据不足时逻辑回退；扩大未来采集属于单独产品与隐私决定。
4. **依据真实发现定向修复。** 不恢复浏览器实例绑定、定时续轮或凭合成夹具填充生产支持目录。删除前复核及恢复副本保留。
